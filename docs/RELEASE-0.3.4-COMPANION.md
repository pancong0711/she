# SHE companion 0.3.4 发布说明

> Release：`v0.3.4-companion.1`
> 日期：2026-11-26

## 变更

- PWA Chat 增加“报告与产物”下载入口；
- 默认 core manifest 指向 `v0.2.0-core.1`；
- 适配 core 0.2.0 artifact API；
- 保留 Gateway、Workspaces、Agents、平台矩阵、自启动和 supervisor 生命周期功能。

## 升级

- 已有 0.3.x supervisor 用户可在 Settings 中检查并安装 0.3.4；
- 然后通过 Core 更新安装 core 0.2.0；
- 0.2.x 或更早版本需要先运行新版 start.sh。
